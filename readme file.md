##  			     VITYARTHI PROJECT

####  				TOPIC: BLACK JACK PYTHON PROJECT

#### Overview of the Project:



This project is a Python-based simulation of the classic card game Blackjack. The game allows players to play against a computerized dealer, following standard Blackjack rules such as hitting and standing, calculating hand values with Ace as 1 or 11, and determining wins, losses, or ties. It is designed to be an interactive, user-friendly console or GUI application that demonstrates core programming concepts like game logic, object-oriented design, and user input handling.



#### Features:



* Fully functional Blackjack gameplay with card dealing, hitting, standing, and dealer logic



* Accurate score calculation including Ace as 1 or 11



* Game state management with winning, losing, busting, and tie conditions



* Shuffling and dealing from a standard 52-card deck



* Clear display of player and dealer hands and scores



* Replay capability to start new rounds without restarting the program



#### Technologies/Tools Used:



* Python 3.x programming language



* Standard Python libraries such as random for shuffling cards



#### Steps to Install \& Run the Project:



* Clone or download the project repository to your local machine.



* Ensure Python 3.x is installed on your system.



* Run the main Python file from the command line or an IDE.



* Follow on-screen instructions to play the game.

#### 

#### Instructions for Testing:



* Launch the game and observe the initial card dealing to player and dealer.



* Test player actions by choosing "hit" to receive additional cards or "stand" to end your turn.



* Verify that scores update correctly and bust conditions are enforced.



* Play several rounds to ensure the deck shuffles and resets properly between games.



* Check that game outcomes such as player win, dealer win, tie, or blackjack are displayed accurately.
